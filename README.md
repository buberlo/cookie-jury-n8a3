# Cookie Jury

> Turn your browser's cookie jar into a trial where trackers are cross-examined.

A local web app imports your browser's cookie list and turns each tracker into a defendant with a motive, evidence, and jury vote. You decide whether the cookie deserves to stay, be exiled, or serve a probation sentence.

## Features
- Import cookies from Chrome, Firefox, or Safari export files
- Generate mock defendant profiles and tracker motives from cookie metadata
- Run a one-minute jury simulation with randomized witness arguments
- Export a consent report that blocks, whitelists, or flags selected cookies

## Stack
- Next.js
- TypeScript
- SQLite

## Getting started
```
npm install && npm run dev
```
